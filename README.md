# 🌸 Floral Garden

## 📖 Sobre o projeto

O **Floral Garden** é um site informativo sobre flores e jardinagem, desenvolvido para praticar os conceitos de **HTML5 e CSS3**. O projeto apresenta uma página inicial, páginas dedicadas a diferentes flores, informações gerais sobre flores e um formulário de contato.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas, links, imagens e formulário.
- **CSS3:** estilização de cores, espaçamentos, menu de navegação e rodapé.

O CSS está incluído na tag `<style>` de cada página HTML. Não é necessário instalar bibliotecas ou dependências.

## ✨ Funcionalidades

- Página inicial de apresentação do Floral Garden.
- Menu de navegação entre as páginas.
- Páginas individuais sobre rosas, lírios e orquídeas, com imagens.
- Página com informações gerais sobre flores.
- Formulário de contato com campos de nome, e-mail e mensagem.
- Estilização visual com CSS e efeito ao passar o mouse sobre os links do menu.

> **Observação:** o formulário possui estrutura HTML e validação básica de campos obrigatórios, mas ainda não está integrado a um servidor para enviar ou armazenar mensagens.

## 🚀 Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code ou em outro editor.
3. Abra o arquivo `css/html/css.html` no navegador.
4. Utilize o menu para acessar as demais páginas.

Opcionalmente, você pode usar a extensão **Live Server** do Visual Studio Code para visualizar o site durante o desenvolvimento.

## 🎯 Objetivo

Aplicar conhecimentos básicos de desenvolvimento web, incluindo organização de páginas HTML, navegação por links, inserção de imagens, formulários e estilização com CSS.

**Floral Garden** — Projeto desenvolvido para fins de aprendizado em desenvolvimento web.
